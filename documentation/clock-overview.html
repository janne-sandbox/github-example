Clock architecture and behavior

Purpose

The example demonstrates a requirements-driven Spring Boot and Angular application. REST supplies the initial value, while a native WebSocket supplies live updates without polling.

Requirement: EXAMPLE-REQ-001. Backend defaults to port 8080; frontend defaults to 4200.

Design caveat: do not build a real clock this way

The one-second WebSocket interval is intentionally inefficient. It creates continuous server scheduling, serialization, network traffic, and client processing for a value the browser can calculate locally.

A production webpage should normally use JavaScript/TypeScript timers and the browser clock to update HH:mm:ss. If server-authoritative time matters, Java can provide an initial timestamp or occasional synchronization point; the page can calculate the elapsed time between synchronizations instead of receiving a message every second.

This project deliberately keeps the inefficient one-second stream because it is a WebSocket demonstration. The frequent updates make connection establishment, server push, payload handling, disconnect detection, and automatic reconnection immediately visible.

ComponentResponsibility
ClockServiceCreates the timestamp and greeting payload.
ClockRestControllerReturns the initial JSON payload.
ClockWebSocketHandlerSends an immediate value, broadcasts updates, and isolates failed sessions.
ClockComponentRenders local HH:mm:ss, connection state, and errors.
ClockService (Angular)Loads REST state, parses WebSocket messages, and controls reconnect/cleanup.

    participant UI as Angular UI

    API-->>UI: ClockPayload
    UI->>WS: Connect /ws/clock
    WS-->>UI: Immediate ClockPayload
    loop Every second
        WS-->>UI: ClockPayload
    end
    WS--xUI: Connection closes
    UI->>UI: Show reconnecting/error state
    UI->>WS: Retry after bounded delay
    WS-->>UI: Connected and live updates resume

A malformed update never replaces the last valid value. Destroying the Angular component closes its socket and cancels pending retries.
