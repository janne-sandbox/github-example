Real-time Hello World clock

Runnable Spring Boot Angular WebSocket

The example combines an initial REST response with one-second WebSocket updates, an Angular status/error UI, local automation, and GitHub Actions examples.

Deliberately impractical clock: sending the time every second over a WebSocket wastes server, network, and client resources. A production webpage should normally advance a clock locally with JavaScript/TypeScript, optionally synchronizing with an authoritative server time at a much lower frequency. This demo uses one-second messages only to make WebSocket connection, delivery, failure, and reconnection behavior easy to observe.
